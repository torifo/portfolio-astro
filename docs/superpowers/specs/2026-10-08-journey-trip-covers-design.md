# 旅の背景画像（2026-10-08）

旅（グループ、今32件）ごとに本人が用意した画像を、旅のカードと旅のページの見出しの背景に敷く。
本人が画像を順に渡し、そろうまでの旅は投稿のサムネで代える。

## 本人が決めたこと

- 出す場所は3か所：旅の一覧のカード（`/journey/trips/`）、旅のページの見出し、県のページの「この県を含む旅」のカード。
  トップの「旅の記録」タイルには出さない。入れてから見た目を調整する
- 画像は、旅の URL 名（slug）をファイル名にしてフォルダに置く
- 画像が無い旅（これから増える旅も）は、その旅の投稿のサムネを代わりに使う

## 置き場と変換

元の画像はリポジトリの外、`~/dev/data/trip-covers/<slug>.<拡張子>` に置く（Instagram のエクスポートと同じ場所）。
元の画像は数 MB あり、位置情報などの EXIF を含むことがあるので、リポジトリには入れない。
同じフォルダの `README.md` に32件の一覧（slug・期間・旅名・届いたかの印）を置く。

`npm run journey:covers`（`scripts/journey/build_trip_covers.py`）がサイト用に変換する。

- 入力は jpg・png・heic・webp。ImageMagick（`build_thumbs.py` と同じ）で自動回転し、**EXIF をすべて消す**（`-strip`）
- 出力は `public/journey/trips/<slug>-800.webp`（カード用）と `<slug>-1600.webp`（見出し・高解像度画面用）。
  縮小だけで拡大はしない（元が1448pxなら1448pxのまま）
- 一覧 `data/journey/trip_covers.json`（slug → 2つのファイルの幅・高さ）を書き出す。サイトはこれを読む。
  `trips.json` は同期のたびに作り直されて新しい項目が消えるので、別のファイルにする。slug は一度決まると変わらない
- 元の画像が出力より新しいときだけ変換し直す。2回目は何もしない
- 旅に無い slug のファイルは飛ばして知らせる。画像がまだ無い旅も一覧で知らせる
- 元の画像を消しても、出力は自動では消さない（フォルダが無い環境で流しても全部消えないように）。消すときは手で消す

## 表示

`src/lib/journey.ts` に `coverFor(trip)` を足す。

- 一覧に slug があれば、本人の画像（`srcset` で800w・1600w）
- 無ければ、その旅のいちばん早い投稿のサムネ（480px）

旅のカードは部品 `TripCard.astro` にまとめ、旅の一覧（年別・地方別の2か所）と県のページで使う。

- 画像を `absolute inset-0 object-cover` で敷き、下から暗いグラデーション（黒 75% → 5%）を重ねる。
  その上に旅名・期間と件数・県（一覧のみ）を白で載せる
- 文字は `text-slate-50`、県のチップは `bg-black/40` と白の細い枠にする。ライトモードで `text-white`・`bg-white/10` などは
  global.css が黒に塗り替えるので使わない（地方のヘッダーと同じ逃げ方）
- 高さをそろえる：一覧は `h-44`（md 以上 `h-48`）、県のページは `h-28`
- カーソルを乗せると画像が少し拡大する（`group-hover:scale-105`、テーマの一覧・投稿のカードと同じ）
- 画像は `loading="lazy" decoding="async"`、`alt=""`（旅名は文字で出ている）

旅のページの見出しは、今の文字だけの見出しを、画像を背景にした幅いっぱいの帯（`h-56`、md 以上 `h-72`、角丸）に替える。
旅名・期間・日数と件数を帯の下側に載せる。通った県・立ち寄り先の行はその下にこれまでどおり置く。

## やらないこと

- トップの「旅の記録」タイル、旅ごとの OGP 画像
- 画像の見せる位置（焦点）の指定。入れてみてから必要なら足す
- nginx のキャッシュ設定（webp は今もキャッシュの指定がなく、毎回 ETag で確かめる）

## 確かめること

- `npm run journey:covers` を2回流して、2回目は何も変わらない。出力に EXIF が残っていない（`magick identify -verbose`）
- 届いている8件は本人の画像、残り24件は投稿のサムネで出る
- ライト・ダーク・スマホ幅で文字が読める
- 本番と比べて、変わるのは旅の一覧・旅のページ・県のページの旅の部分だけ
