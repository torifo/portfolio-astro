# 聖地巡礼の作品ページにシリーズの PV を全部並べる（2026-10-31）

作品のページの「公式の映像・サイト」は PV 1本と公式サイトのカード1枚だけだった。
俺ガイルは TV が3期（1期・続・完）あるのに、出ていたのは10周年記念 PV と「完」のサイトだけ。
シリーズのある作品は、期ごとの PV とサイトを全部並べる。

## 本人が決めたこと

- TV シリーズは全期入れる
- TV 以外（劇場版・総集編・スピンオフ・OVA）は、その作品自体に聖地巡礼のモデル地があるときだけ入れる。
  へやキャン△のようなスピンオフも、モデル地があれば入れる
- 実写（ドラマ・映画）は絶対に入れない。一覧にも名前を出さない
- 並べ方は「PV を格子に並べ、公式サイトはその下に期ごとのリンクでまとめる」。1件しかない作品は今のまま
- （10-31 追記）TV の期は「2期（続）」のように数字＋名前で書く。PV はトップの旅の帯と同じく横に流れ続ける帯にする。
  ただし全部が横に収まる幅なら流さずに並べるだけ（足りないときだけ流れる）

## データ

`data/journey/work_links.json` の作品に `series` を足す（人が書く。放送順）。

```json
"series": [
  {
    "label": "続",
    "year": 2015,
    "kind": "tv",
    "youtube": { "id": "…", "title": "…", "channel": "…" },
    "officialSite": "https://…"
  }
]
```

- `label` は期を見分ける短い名前。TV は「2期（続）」「5期（LIMIT BREAK）」の形、TV 以外は名前のまま（劇場版・Re:RIDE・へやキャン△ など）。`kind` は tv / movie / compilation / spinoff / ova
- PV は権利者の公式チャンネルのものだけ。YouTube の oEmbed で題名とチャンネル名を確かめて写す
- `officialSite` はその期の内容を今も出しているページだけ（200 で、別の期やポータルの入口へ飛ばされない）。無ければ書かない
- 作品の `youtube`・`officialSite`・`site` はそのまま残す（`series` が1件以下の作品と、`series` に公式サイトが1つも無いときの代わりに使う）

## 表示

`src/components/journey/OfficialEmbeds.astro`

- `series` が2件以上：見出し「公式の映像」の下に PV を並べる。サムネの下に名前と年とチャンネル
  - 全部が横に収まる（1枚 220px 以上）なら等分に並べるだけ。境目の幅は PV の数で変わるので、ビルドのときに出してコンテナクエリにする
  - 収まらなければ、トップの旅の帯と同じ流れる帯（動きは `src/lib/reel.ts` を共用）。PV が少ないと1周が短くつなぎ目が見えるので、6枚以上になるまで繰り返す
  - 押した PV は帯の上の枠で再生し、その間は帯を止める。「閉じる」で戻る
- その下の「公式サイト」も PV と同じ大きさのサムネで同じように並べる（同じ URL は1つにまとめ、名前をつなげる。並びの部品は `ReelStrip.astro`）。
  画像はサイトがリンク共有用に出している横長の画像（`siteImage`、公式サイトから直接）。小さなロゴ・ほかの期と同じ画像・画像なしの期は、色の帯に名前を大きく書いたカード。
  期のサイトが1つも無ければ作品の `officialSite` を1つ出す
- ライトモードで黒くならない色（text-gray-100）は使わない
- `series` が1件以下：今までどおり（PV 1本＋公式サイトのカード）
- 伏せている作品（hidden）は作品ページが無いので対象外
